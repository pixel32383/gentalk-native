# GENTALK 정책 문서 게시 방법

이 폴더는 GitHub Pages용 공개 문서입니다.

1. GitHub 저장소의 **Settings → Pages**에서 배포 원본을 **Deploy from a branch**로 선택합니다.
2. 브랜치는 `master`, 폴더는 `/docs`로 선택한 뒤 **Save**를 누릅니다.
3. 발급된 공개 주소에서 아래 페이지가 열리는지 확인합니다.
   - `/privacy-policy.html`
   - `/terms-of-service.html`
4. 그 URL을 Google Play Console의 개인정보처리방침 항목에 등록하고, 앱 내부 링크에도 넣습니다.

이 저장소의 공개 주소는 `https://pixel32383.github.io/gentalk-native/`입니다.
