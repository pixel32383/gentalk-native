# GENTALK 정책 문서 게시 방법

이 폴더는 GitHub Pages용 공개 문서입니다.

1. 이 프로젝트를 GitHub의 `gentalk-native` 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 배포 원본을 `main` 브랜치의 `/docs` 폴더로 선택합니다.
3. 발급된 공개 주소에서 아래 페이지가 열리는지 확인합니다.
   - `/privacy-policy.html`
   - `/terms-of-service.html`
4. 그 URL을 Google Play Console의 개인정보처리방침 항목에 등록하고, 앱 내부 링크에도 넣습니다.

GitHub Pages 주소는 일반적으로 `https://<GitHub-아이디>.github.io/<저장소-이름>/` 형식입니다.
