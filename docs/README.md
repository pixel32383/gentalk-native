## 공개 정책 문서

이 폴더의 HTML 파일은 GitHub Pages에서 제공합니다. 앱 내부의 약관·개인정보처리방침 링크와 연결되어 있으므로 파일 이름과 공개 주소를 유지합니다.

- `index.html`: 정책 문서 안내
- `privacy-policy.html`: 개인정보처리방침
- `terms-of-service.html`: 서비스 이용약관

### GitHub Pages 설정

1. GitHub 저장소의 **Settings → Pages**에서 배포 원본을 **Deploy from a branch**로 선택합니다.
2. 브랜치는 `master`, 폴더는 `/docs`로 선택한 뒤 **Save**를 누릅니다.
3. 발급된 공개 주소에서 아래 페이지가 열리는지 확인합니다.
   - `/privacy-policy.html`
   - `/terms-of-service.html`
4. 앱 내부의 정책 문서 링크가 같은 공개 주소를 가리키는지 확인합니다.

이 저장소의 공개 주소는 `https://pixel32383.github.io/gentalk-native/`입니다.
